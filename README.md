# 🦍 Billy Gorilla Bot

Телеграм-бот для пацанов, которые хотят накачаться и стать лучше.

## Фичи
- Регистрация с параметрами (возраст, рост, вес, питание, вода)
- Трекер воды и еды с круговыми графиками
- Программа тренировок (PRO, 199⭐)
- Уроки питания (PRO)
- Стрик-система как в Duolingo
- Титулы дня
- Лиги и зал позора
- Счётчик no-fap
- Брутто-сила
- Ежедневные напоминания (120+ фраз)
- Админ-панель с рассылкой

## Деплой
1. Форкни / залей на GitHub
2. Зайди на railway.app → New Project → Deploy from GitHub
3. Добавь переменные: `BOT_TOKEN`, `ADMIN_ID`, `CHANNEL_ID`
4. Railway сам соберёт Dockerfile и запустит
